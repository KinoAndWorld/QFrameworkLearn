# Unity拼图游戏 - 快速开始指南

本指南将帮助你快速设置并运行拼图游戏项目。按照以下步骤操作，你将能够创建一个基础的拼图游戏场景。

## 前提条件

- Unity 2019.4 或更高版本
- 基本的Unity使用知识

## 1. 创建基础场景

### 1.1 创建UI画布

1. 在Unity编辑器中，创建一个新场景
2. 右键点击Hierarchy窗口，选择`UI > Canvas`创建UI画布
3. 确保Canvas命名为"Canvas"（脚本会直接使用这个名称查找）
4. 设置Canvas的渲染模式为`Screen Space - Overlay`
5. 添加一个`UI > Image`作为背景（可选）

### 1.2 创建拼图管理器

1. 在Hierarchy窗口，创建一个空物体，命名为"PuzzleManager"
2. 将`New_Grid.cs`脚本添加到PuzzleManager物体上

## 2. 创建拼图碎片预制体

1. 在项目中创建一个Prefabs文件夹
2. 右键点击Hierarchy窗口，选择`UI > Image`创建一个UI图像
3. 将`grid.cs`脚本添加到这个图像上
4. 将这个图像拖放到Prefabs文件夹中创建预制体，命名为"GridPiece"
5. 从Hierarchy中删除刚才创建的图像实例

## 3. 配置拼图管理器

选择PuzzleManager物体，在Inspector面板中配置New_Grid组件：

1. **Grid**: 拖放刚才创建的GridPiece预制体到此处
2. **Number**: 设置为3（表示3×3的拼图）
3. **The With**: 设置为300（拼图在UI中显示的宽度）
4. **Main Picture**: 拖放一张你希望用作拼图的图片（必须是Texture2D类型）

> **注意**: 要确保图片已经被导入为Texture2D类型，可能需要在导入设置中将其设置为"Sprite (2D and UI)"或"Default"，并确保"Read/Write Enabled"选项已开启。

## 4. 创建游戏控制按钮

### 4.1 创建生成按钮

1. 右键点击Canvas，选择`UI > Button`
2. 将按钮重命名为"GenerateButton"
3. 设置按钮的位置到屏幕下方合适位置
4. 修改按钮文本为"生成拼图"

### 4.2 创建裁剪按钮

1. 再创建一个按钮，重命名为"ClipButton"
2. 设置按钮的位置到"GenerateButton"旁边
3. 修改按钮文本为"裁剪拼图"

### 4.3 配置按钮功能

1. 选择PuzzleManager物体
2. 在Inspector窗口中找到"GenerateButton"按钮的组件
3. 在OnClick()事件中，点击"+"按钮
4. 将PuzzleManager拖放到对象字段
5. 在函数下拉菜单中，选择`New_Grid > CreatGrids()`
6. 对"ClipButton"按钮执行相同操作，但选择`New_Grid > beClip()`函数

## 5. 运行游戏

1. 点击Unity顶部的播放按钮，运行游戏
2. 在游戏运行时，首先点击"生成拼图"按钮创建拼图块
3. 然后点击"裁剪拼图"按钮将图片裁剪到各个拼图块上

## 故障排除

### 拼图碎片未正确显示

- 确保Canvas对象名称为"Canvas"
- 检查Main Picture是否已正确设置且可读写
- 确保Grid预制体包含正确的grid组件和Image组件

### 凹凸边缘不匹配

- 当前版本使用固定的凹凸设置，可以在New_Grid.cs文件的CreatGrids方法中修改初始化部分

### 性能问题

- 对于复杂图片或高网格数量，可能需要降低图片分辨率或优化beClip方法中的像素处理代码
