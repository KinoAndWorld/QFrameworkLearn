# Unity拼图游戏 - 项目说明文档

## 项目概述

这是一个基于Unity引擎开发的拼图游戏项目。该项目主要实现了将一张完整图片切分成多个带有凹凸边缘的拼图块的功能，可用于开发拼图类游戏。项目使用C#作为开发语言，基于Unity的UI系统实现界面。

## 核心功能

1. **图片切分**：将一张完整图片按照指定的网格数量切分成多个拼图碎片
2. **凹凸边缘生成**：为每个拼图碎片生成带有凹凸边缘的外形，使其能够与相邻的拼图块拼接
3. **纹理映射**：将原始图片上对应区域的像素准确映射到切分后的拼图碎片上

## 组件详解

### 1. grid.cs

这是一个基础组件，用于定义每个拼图碎片的属性。

#### 主要属性
- `circle_up`：上边缘的凹凸状态 (-1: 凹, 0: 平, 1: 凸)
- `circle_right`：右边缘的凹凸状态 (-1: 凹, 0: 平, 1: 凸)
- `circle_down`：下边缘的凹凸状态 (-1: 凹, 0: 平, 1: 凸)
- `circle_left`：左边缘的凹凸状态 (-1: 凹, 0: 平, 1: 凸)

这些属性决定了每个拼图碎片边缘的形状，使拼图碎片能够相互吻合。

### 2. New_Grid.cs

这是项目的主要管理脚本，负责拼图的生成和处理。

#### 主要属性
- `grid`：拼图碎片的预制体，需要包含grid组件
- `number`：拼图的网格数量（如：3×3、4×4等）
- `the_with`：界面中显示的拼图宽度
- `MainPicture`：需要被切分的原始图片

#### 主要方法

##### CreatGrids()
此方法用于在场景中生成指定数量的拼图碎片网格。

**实现逻辑**：
1. 根据设定的网格数量计算每个拼图碎片的大小
2. 在场景中按照网格位置实例化拼图碎片
3. 初始化每个拼图碎片的凹凸属性（当前实现中包含了一个9×9网格的固定初始化示例）

##### beClip()
此方法用于处理拼图碎片的图像，将原图对应区域的像素映射到拼图碎片上，并根据凹凸属性处理边缘。

**实现逻辑**：
1. 遍历每个拼图碎片
2. 为每个碎片创建新的纹理
3. 从原图对应位置复制像素到新纹理
4. 根据每个边缘的凹凸属性进行特殊处理：
   - 如果边缘为"凹"，则计算圆形凹入区域并将对应像素设置为透明
   - 如果边缘为"凸"，则计算圆形凸出区域，并从原图获取对应区域的像素
5. 将处理好的纹理应用到拼图碎片上

**图像处理算法**：
- 使用数学方程(x - 圆心x)² + (y - 圆心y)² = r²计算圆形凹凸边缘
- 凹陷部分通过设置像素为透明来实现
- 凸出部分通过从原图获取超出标准矩形区域的像素来实现

## 使用方法

1. **设置场景**：
   - 确保场景中有一个名为"Canvas"的UI画布

2. **配置New_Grid组件**：
   - 将New_Grid脚本添加到一个游戏对象上
   - 设置拼图碎片预制体(grid)，该预制体需要包含Image组件和grid组件
   - 设置网格数量(number)，例如3表示3×3的网格
   - 设置界面中显示的拼图宽度(the_with)
   - 设置要切分的图片(MainPicture)

3. **生成拼图**：
   - 调用CreatGrids()方法生成拼图碎片
   - 调用beClip()方法处理拼图碎片的图像

## 拓展功能建议

1. **随机凹凸生成**：实现自动随机生成拼图碎片的凹凸属性，而不是使用固定的初始化方式
2. **拖拽交互**：添加拖拽功能，使玩家能够移动拼图碎片
3. **吸附效果**：当拼图碎片靠近正确位置时，实现吸附效果
4. **游戏进度跟踪**：添加判断拼图是否完成的逻辑和界面显示
5. **难度设置**：允许玩家选择不同的网格数量，以调整游戏难度

## 系统要求

- Unity 2019.4 或更高版本
- 支持UI系统

## 注意事项

- 当前实现中，拼图的凹凸属性是硬编码的，实际应用中可能需要改为随机生成或从配置中读取
- 在处理大图片或高网格数量时，可能需要优化图像处理算法以提高性能
